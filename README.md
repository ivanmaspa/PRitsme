## 📖 О проекте

**PRitsme** — это независимая мобильная и серверная экосистема для игроков **Pixel Royale**, созданная для мгновенного доступа к расписанию ивентов, актуальным картам и тактическим секторам без зависимости от внешних онлайн-серверов или HTTPS.

### 🌟 Ключевые возможности:

1. **100% Offline-First / Zero-HTTPS:**
   - Все расчеты времени и расписаний производятся на устройстве по московскому времени (MSK / UTC+3).
   - Встроенные аудио-сигналы синтезируются на лету через Web Audio API без внешних аудио-файлов.
   - Полноценная тактическая карта высокого разрешения встроена прямо в приложение (открывается мгновенно даже в режиме «В самолете»).

2. **Защита от спама и лимит на карту (10 минут):**
   - Кнопка запроса карты в приложении и в Telegram-боте снабжена **10-минутным кулдауном**.
   - Динамический таймер и кольцо охлаждения наглядно показывают оставшееся время до следующего запроса.

3. **Синхронизация с игровыми ботами и чатами:**
   - `@ndjdhfbdbs_bot` — прямой доступ к игровому чат-боту Pixel Royale.
   - `@PBMap_bot` — бот карты и аирдроп-бомб.
   - `@masiksssgegai_bot` — экосистемный бот PRitsme.
   - Группа **«Союз Е-Р-О-П»** (`ID: -1003949456661`) — координация и получение карт.

4. **23 региона карты:**
   - Азия, Антарктида, Африка, Евразия, Европа (ЕС), Океания, Сааремаа, Северная Америка, Южная Америка, Бангладеш, Бразилия, Израиль, Индия, Казахстан, Канада, Китай, Конго, Монголия, Россия, США, Того, Украина, Шри-Ланка.

5. **Расписание ивентов:**
   - **Аирдропы (каждые 2 часа):** 01:00, 03:00, 05:00, 07:00, 09:00, 11:00, 13:00, 15:00, 17:00, 20:00, 21:00, 23:00 МСК.
   - **Вечерняя Капча:** Ежедневно в **19:00:00 (МСК)**.
   - Автоматические оповещения во все подключенные группы за 5 минут и 1 минуту.
